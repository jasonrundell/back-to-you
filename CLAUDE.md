# Project rules

- ElevenLabs Voice Design prompts (voice description text, e.g. in
  `sounds/*/elevenlabs-prompt.md` and `ELEVENLABS-VOICE-PROMPT.md`) must be
  **500 characters or fewer**. Check with `wc -c` before finalizing.
